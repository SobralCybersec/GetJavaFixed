# JavaRf

JavaRf is a desktop AI workspace for Java refactoring, code review, terminal-driven investigation, and guarded edit workflows.

## What It Does

- Multi-provider AI chat with local and cloud model backends
- Java repository intake plus findings-driven refactor previews
- Built-in agent personas and read-only subagents
- Managed MCP support for remote research providers and local specialist bridges
- Settings-driven UI customization, themes, shortcuts, and agent controls

## Current Highlights

- `en` and `pt-BR` app localization with system-locale fallback
- Tokyo Ghoul CCG investigator agent rebrand for built-in agents and subagents
- Generic MCP provider model for remote HTTP MCPs
- Managed local MCP preset support, including `x64dbg`
- About-page and README acknowledgements
