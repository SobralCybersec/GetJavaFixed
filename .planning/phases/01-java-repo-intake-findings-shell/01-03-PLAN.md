## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard→analysis command | User-triggered analysis crosses from React into native background work |
| analysis worker→filesystem watcher | Native code observes repository files and emits progress back to the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Elevation of Privilege | analysis start path | mitigate | Expose only fixed native commands for analysis; no free-form shell argv or terminal bridging. |
| T-01-08 | Denial of Service | watcher-backed analysis | mitigate | Reuse bounded watch patterns and skip generated directories so progress does not flood from build output trees. |
| T-01-09 | Repudiation | progress lifecycle | accept | Inline progress is transient in Phase 1; later phases can add persisted history if needed. |
| T-01-SC | Tampering | command/event surface | mitigate | Keep the command set local to Tauri IPC and validate repo context before starting analysis. |
</threat_model>
