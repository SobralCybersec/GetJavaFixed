| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Spoofing | findings ranking UI | mitigate | Keep ranking deterministic in `useFindings.ts` and render priority from trusted finding data rather than ad hoc client sorting. |
| T-01-11 | Information Disclosure | detail panel | accept | Show only rationale, principles, and relative affected paths already derived from the analyzed repo; no secret or external content is introduced in Phase 1. |
| T-01-12 | Tampering | selected finding state | mitigate | Reconcile selection when findings update and auto-select only from the current ranked result set. |
| T-01-SC | Tampering | UI dependency surface | mitigate | Reuse existing local shadcn primitives (`badge`, `sheet`, `card`, `progress`) and avoid new packages in this plan. |
</threat_model>
